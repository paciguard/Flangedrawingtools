# 法兰工具 Web 原型

ASP.NET Core 8 项目。运行 `dotnet run`，打开终端显示的本地地址。

本原型从原始工作簿的四个数据源提取已保存的单元格值，提供基本的标准、压力和口径筛选及原始记录查看。它不实现工作簿的全部校验、命名范围、VBA、图纸、保温逻辑或完整组合筛选，不能用于制造出图。原始数据为工作簿保存的值，未独立验证标准尺寸。

原工作簿的部分图形已转换为图片，仅作外形参考；其动态尺寸标注、注释和图纸生成均未完成，图片不适合出图。选择的密封面和类型目前没有完整的组合有效性校验。

公开仓库的源代码分支不包含工作簿提取的数据文件和图形资产；必须在本地提供 `Data/flanges.json` 和相应图片才能显示查询数据及预览。请勿将未经授权的数据提交到公开仓库。
