# 法兰图纸生成工具 Web 原型

ASP.NET Core 8 项目。在本目录运行 `dotnet run`，访问终端显示的本地地址，或用 Visual Studio 打开 `FlangeWeb.sln`。

标准、压力、尺寸和下拉列表来自 `法兰图纸生成工具_2026111201.xlsm` 的已保存值与命名区域。夹套选择强制保温为“有”，类型限定为整体法兰。数据尚未独立核验，不得用于制造出图。

- 从工作簿 12 个绘图模板提取了文本框的单元格链接、公式和相对位置。
- 整体法兰 RF、F、M、RJ 的部分主尺寸已试验性连接；完整标注、公差、技术要求、保温法兰和非整体法兰绘图尚未完成。
- 组合校验和尺寸计算仅移植了部分工作簿逻辑，尚需与工作簿及标准逐项比对。
- 页面可调用浏览器打印对话框，采用 A4 纵向草稿布局。打印效果与分页尚未在目标浏览器中验证。
- 在仓库根目录执行 `dotnet run --project FlangeWeb.Checks` 和 `node FlangeWeb.Checks/annotation-check.cjs` 运行现有检查。

尺寸文本框映射已覆盖 12 个模板中可直接从数据源追溯的部分字段。尚未映射的计算尺寸、公差、技术注释及保温配对图仍为空；绘图和打印均为草稿，不能作为制造依据。
