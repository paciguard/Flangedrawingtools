# 法兰图纸生成工具 Web 原型

ASP.NET Core 8 项目。在本目录运行 `dotnet run`，访问终端显示的本地地址，或用 Visual Studio 打开 `FlangeWeb.sln`。

标准、压力、尺寸和下拉列表来自 `法兰图纸生成工具_2026111201.xlsm` 的已保存值与命名区域。工具仅提供整体法兰（IF）；夹套选择强制保温为“有”。报告省略空值及焊管侧字段。数据尚未独立核验，不得用于制造出图。

- 从工作簿 12 个绘图模板提取了文本框的单元格链接、公式和相对位置。
- RF、F、M、RJ 的整体法兰图形中，已连接可直接追溯的数据字段、工作簿中的厚度计算及一部分公差表规则。
- 组合校验和尺寸计算仅移植了部分工作簿逻辑，尚需与工作簿及标准逐项比对。
- 点击“导出 PDF”可直接生成单页 A4 纵向 PDF，弹出保存对话框，并按进口、出口标准、压力、口径、密封面和时间建议文件名。需要支持文件保存选择器的 Chrome 或 Edge，以及 localhost 或 HTTPS；PDF 中的绘图以高分辨率图片保存。已用浏览器样例检查两张图；其他组合仍需逐项核验。
- 在仓库根目录执行 `dotnet run --project FlangeWeb.Checks` 和 `node FlangeWeb.Checks/annotation-check.cjs` 运行现有检查。

部分尺寸、公差、技术注释及保温配对图尚未完成；绘图与打印结果尚未逐项对照原工作簿，不能作为制造依据。
